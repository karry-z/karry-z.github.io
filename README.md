# Kairui Zhang

Astro source for the personal academic website at `https://karry-z.github.io/`.

## Local commands

```sh
npm run dev
npm run check
npm run build
npm run preview
```

## Editing map

- Page and UI copy: `src/data/copy.ts`
- Personal profile, CV path, footer links: `src/data/profile.ts`
- Project and publication entries: `src/data/works.ts`
- Homepage news: `src/data/news.ts`
- Routes and localized paths: `src/data/nav.ts`
- Layout and rendering components: `src/pages/`, `src/components/`, `src/layouts/`

Deployment is configured for GitHub Pages through GitHub Actions, but this branch has not been pushed or deployed.
